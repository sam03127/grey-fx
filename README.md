# Grey FX

A cinematic editing studio website inspired by the supplied Sam portfolio's visual language, redesigned as a service/business website rather than a personal portfolio.

## Stack
- React + Vite
- Tailwind CSS
- GSAP
- Framer Motion

## Run
npm install
npm run dev

## Build
npm run build

## Customize
- Replace project names/content in `src/components/Work.jsx`.
- Update prices in `src/components/Pricing.jsx`.
- Change contact email in `src/components/CTA.jsx`.
- Add actual reel/video thumbnails where desired.
